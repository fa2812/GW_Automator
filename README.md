# GASWorkS-Automator
Built on Python 3.11.9

An application that automates publishing reports in GASWorkS using GUI automation (pyautogui).

Reports that will be published include:
- Pipe Data Report
- Node Data Report
- Customer Data Report
- System Summary Report

Reports are published to a designated "Outputs" folder, which can be opened through the app.

Additional features
- Allows for UKPS project folders (Gas Design) to be opened quickly on 3 tabs in a single File Explorer window (Windows 11 only).
- A "Green" button to keep PC awake by simulating cursor movement and clicks on the top left of the main display.
